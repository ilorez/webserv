webserv
test dashboard.

Two independent test flows — Normal and CGI requests. Each runs in order: upload → read → post with body → delete. Steps unlock after the previous one succeeds.

# normal requests Static Files
1
POST/upload/test.txt
Creates test.txt on the server. Body is sent as plain text.
waiting…
file created — now fetch it
2
GET/upload/test.txt
Fetches the file that was just created. Response body shown below.
waiting…
file confirmed — now delete it
3
DELETE/upload/test.txt
Removes test.txt from the server.
waiting…
# cgi requests CGI / Python
1
POST/cgi-bin/upload
Uploads hello.py to cgi-bin. Filename via Content-Disposition.
waiting…
script uploaded — run it with GET (no stdin)
2
GET/cgi-bin/hello.py
Executes the script. No stdin. Server returns stdout as response body.
waiting…
GET works — now POST with body as stdin
3
POST/cgi-bin/hello.py
Executes the script. POST body is passed as stdin to the script.
waiting…
POST with stdin works — clean up
4
DELETE/cgi-bin/hello.py
Removes hello.py from cgi-bin.
waiting…
